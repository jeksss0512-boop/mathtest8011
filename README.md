# 수학교육 연구용 온라인테스트

중학교 수학 문항을 이용해 수학교육 연구용 온라인검사와 풀이 대화 활동을 작게 검증하는 프로젝트입니다.

현재는 학생 ID를 입력하고 3개 문항을 푼 뒤, 제출 결과와 저장될 데이터를 화면에서 확인하는 1차 시험판입니다.

추가로 PDF에서 확인한 중학교 삼각비 문제 1개와 예시 AI 질문을 사용하는 대화형 최소 프로토타입도 구현되어 있습니다.

## 현재 구현된 기능

- 학생 ID 입력
- 일차방정식 문항 3개
  - 객관식 2개
  - 단답형 1개
- 문항별 답 입력
- 문항별 풀이 시간 측정
- 미응답 문항 안내
- 자동 채점
- 결과 요약 표
- 응답 데이터 표와 원본 JSON 확인
- 마지막 제출 결과를 브라우저 `localStorage`에 저장

현재 문항은 연구용 최종 문항이 아니라 화면, 채점, 데이터 구조를 확인하기 위한 시험용 문항입니다.

## 실행 방법

가장 간단한 방법은 `app/index.html`을 웹 브라우저에서 여는 것입니다.

개발 서버를 사용할 경우 프로젝트 폴더에서 다음처럼 실행할 수 있습니다.

```powershell
python -m http.server 8765
```

그 다음 [http://127.0.0.1:8765/app/index.html](http://127.0.0.1:8765/app/index.html)을 엽니다.

삼각비 대화 프로토타입은 `http://127.0.0.1:8765/app/trig-chatbot/index.html`에서 확인하고, 연구자 로그는 `http://127.0.0.1:8765/app/trig-chatbot/researcher.html`에서 확인합니다.

## 화면 흐름

```text
학생 ID 입력 → 3개 문항 풀이 → 제출 → 결과 표 및 저장 데이터 확인
```

현재 시험판은 3개 문항을 한 화면에 보여 줍니다. 계획 문서에 있던 문항별 별도 화면과 별도의 제출 확인 화면은 아직 구현하지 않았습니다.

## 저장 데이터

제출 시 다음 구조의 데이터가 만들어집니다.

- `attempt`: 학생 ID, 검사 ID, 응시 시작 시각, 제출 시각, 총점
- `responses`: 문항별 학생 답, 정답, 정답 여부, 점수, 풀이 시간, 응답 시각

현재 저장 위치는 브라우저의 `localStorage`이며 저장 키는 `lastMathTestAttempt`입니다. 실제 연구 운영용 데이터베이스 저장은 아직 연결하지 않았습니다.

## 아직 구현하지 않은 연구 기능

- A/B 집단 배정
- 사전검사·사후검사 구분
- 동형검사 관리
- 연구자 관리자 화면
- 로그인과 권한 관리
- Supabase에 실제 응시 데이터 저장
- 개인정보 보호와 연구 운영용 백업 체계

Supabase에는 데이터 구조를 위한 테이블을 준비했지만, 현재 웹앱과 Supabase는 연결되어 있지 않습니다. 따라서 이 시험판에서 입력한 데이터는 연구용 서버 데이터로 사용하면 안 됩니다.

## 삼각비 대화 프로토타입

- 학생 ID 입력 후 삼각비 문제 1개 확인
- 학생 생각과 준비된 예시 질문의 반복 대화
- `localStorage` 임시 저장 및 새로고침 후 이어하기
- 활동 종료 시 `completed` 상태 기록
- 연구자 화면에서 JSON·CSV 로그 내보내기
- 학생 화면에는 연구용 분류값을 표시하지 않음
- 실제 AI API와 Supabase DB는 아직 연결하지 않음

## 배포 상태

Vercel 배포 프로젝트는 생성되어 있지만, 현재 배포 주소가 Vercel 로그인 화면으로 보호되어 외부 공개가 완료된 상태는 아닙니다. 배포 주소와 공개 설정은 학생 데이터를 연결하기 전에 보안 설정을 먼저 확인해야 합니다.
