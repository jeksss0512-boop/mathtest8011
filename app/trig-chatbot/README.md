# 삼각비 생각 나누기 프로토타입

연구용 AI 챗봇의 화면 흐름과 연구 로그 형태를 확인하기 위한 연습용 프로토타입입니다.

## 실행

프로젝트 폴더에서 로컬 서버를 실행합니다.

```powershell
python -m http.server 8765
```

학생 화면:

`http://127.0.0.1:8765/app/trig-chatbot/index.html`

연구자 로그 화면:

`http://127.0.0.1:8765/app/trig-chatbot/researcher.html`

## 현재 기능

- 가명 학생 ID 입력
- 삼각비 문제 1개와 PDF에서 확인한 그림 표시
- 학생 첫 생각과 후속 응답 입력
- 준비된 예시 질문 3개 반복
- 활동 종료와 저장 상태 안내
- 브라우저 `localStorage` 임시 저장
- 연구자용 JSON·CSV 내보내기
- 학생 화면에서 연구용 메타데이터 숨김
- 활동 종료 중복 클릭 방지

## 아직 연결하지 않은 것

- 실제 AI API
- Supabase 데이터베이스
- 로그인과 연구자 권한
- 실제 연구 운영용 개인정보 보호 체계

현재 로그의 `prototype_live` 값은 `prototype`이며, 실제 학생 자료가 아닌 가상 테스트에만 사용해야 합니다.
