# 앱 시험판

이 폴더는 학생 ID 입력부터 제출 결과 확인까지를 시험하는 정적 웹앱입니다.

## 현재 흐름

```text
학생 ID 입력 → 한 화면에서 3개 문항 풀이 → 제출 → 결과 및 저장 데이터 확인
```

## 파일

- `index.html`: 화면 구조
- `styles.css`: 차분한 검사 화면 디자인
- `app.js`: 문항, 답 입력, 시간 측정, 채점, 결과 표시, `localStorage` 저장

## 문항

- 객관식: `3x + 5 = 17`, `2(x - 3) = 10`
- 단답형: `5x - 7 = 18`
- 모든 문항 1점, 총점 3점

## 주의

현재 결과는 브라우저에만 저장됩니다. 연구 운영용 Supabase 저장은 아직 연결되지 않았습니다.
