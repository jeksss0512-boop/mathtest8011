# 일차방정식 3문항 온라인테스트

학생 ID를 입력하고 중학교 일차방정식 수준의 문항 3개를 푼 뒤, 제출 결과와 저장 데이터를 화면에서 확인하는 1차 시험판입니다.

## 실행

`index.html` 파일을 웹 브라우저에서 열면 됩니다.

## 포함된 기능

- 학생 ID 입력
- 객관식 2문항
- 단답형 1문항
- 문항별 풀이 시간 측정
- 제출 전 미응답 확인
- 자동 채점
- 결과 요약 표
- 문항별 저장 데이터 표
- 마지막 제출 결과를 브라우저의 `localStorage`에 저장

## 시험용 문항

1. `3x + 5 = 17`에서 x의 값은? 객관식
2. `2(x - 3) = 10`에서 x의 값은? 객관식
3. `5x - 7 = 18`에서 x의 값은? 단답형

현재 점수는 모든 문항 1점으로 계산합니다.
