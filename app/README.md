# 앱 시험판

이 폴더에는 두 개의 정적 웹앱 시험판이 있습니다.

## 현재 흐름

```text
학생 ID 입력 → 한 화면에서 3개 문항 풀이 → 제출 → 결과 및 저장 데이터 확인
```

## 파일

- `index.html`: 화면 구조
- `styles.css`: 차분한 검사 화면 디자인
- `app.js`: 문항, 답 입력, 시간 측정, 채점, 결과 표시, `localStorage` 저장

## 문항

- 객관식: `3x + 5 = 17`, `2(x - 3) = 10`
- 단답형: `5x - 7 = 18`
- 모든 문항 1점, 총점 3점

## 주의

현재 결과는 브라우저에만 저장됩니다. 연구 운영용 Supabase 저장은 아직 연결되지 않았습니다.

## 삼각비 대화 프로토타입

`trig-chatbot/` 폴더에는 다음 기능이 들어 있습니다.

- PDF에서 확인한 삼각비 문제 1개
- 학생 생각과 예시 질문이 이어지는 대화
- 새로고침 후 `localStorage` 임시 저장 복원
- 활동 종료 후 연구자용 JSON·CSV 로그 내보내기
- 예시 질문을 구분하는 `prototype` 로그 값

학생 화면: `trig-chatbot/index.html`

연구자 확인 화면: `trig-chatbot/researcher.html`

실제 AI API와 Supabase DB는 아직 연결하지 않았습니다.
